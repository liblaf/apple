# Small-fixture tensor-stress recovery

## Question and scope

Can the tensor-control inverse map recover a displacement target that was generated by the same forward model? This study uses the exact two-tetrahedron fixture, material mixture, and nine free coordinates validated by study 12. It tests optimizer behavior on CPU before another face run. It does not test anatomy, face-scale capacity, or uniqueness of the recovered stress.

The control in each cell is the six-coordinate orthonormal representation of the symmetric tensor `Z = Q / Qref`. Every update is projected to `0 <= Z <= 10 I`. The target uses rotated positive-definite tensors with dimensionless eigenvalues `[0.7, 1.5, 2.4]` and `[0.5, 1.2, 2.0]`, strictly inside that box. Its accepted equilibrium moves by RMS `0.1293646544` fixture length units from rest.

## Gradient check

The inverse gradient uses the dense nine-coordinate implicit system

`H^T lambda = dL/dy`, `dL/dZ = -(dE_y/dZ)^T lambda`.

One fixed direction was checked by centered finite differences at several step sizes. The acceptance threshold remained `2e-4`; the forward solver and its `1e-8` equilibrium-gradient acceptance rule were unchanged.

## Fixed 256-update screen

The raw loss is mean squared displacement over all 15 fixture coordinates. A single positive multiplier, `0.0015952988324030857`, makes the initial 12-control gradient RMS equal the saved face plain-PSD step-64 fit-gradient RMS, `4.783391513852665e-5`. This scaling does not change the minimizer.

The baseline uses the face setting `eps=1e-2`, `lr=0.3`. Before seeing recovery outcomes, the two candidate learning rates were calibrated so their first projected per-cell Frobenius stress-step RMS was twice the baseline value.

| arm | learning rate | first projected stress-step RMS (MPa) | RMS after 256 | error / target motion | projected-gradient final / initial |
| --- | ---: | ---: | ---: | ---: | ---: |
| `eps=1e-2` | `0.3` | `6.96095e-5` | `0.0578442` | `0.447140` | `0.239137` |
| `eps=1e-4` | `0.00984802` | `1.39219e-4` | `0.0331723` | `0.256425` | `0.111989` |
| `eps=1e-6` | `0.00354034` | `1.39219e-4` | `0.0302834` | `0.234093` | `0.144179` |

The declared rule selects the smallest final displacement MSE, with projected-gradient reduction only as a tie-breaker. It therefore selects `eps=1e-6`. Agreement with the generating stress is recorded only as a diagnostic and never enters selection.

## Why 4096 updates were insufficient

The selected setting was rerun unchanged from zero. At update 4096 its displacement RMS was `0.00833495`, or `0.0644299` of target motion, so the strict `1e-3` recovery gate failed. The v3 run remains failed.

A dense endpoint diagnosis rules out the PSD box as the cause. Both cell tensors were strictly inside the box, with eigenvalues from `0.00142256` to `0.0264049 MPa` against a `0.302013 MPa` cap, and the projection RMS was `1.68e-16`. The displacement Jacobian `S = -H^-1 E_yZ` had singular values from `1.18429` to `0.0134124`; `99.8762%` of residual energy lay in the weakest mode and `99.9969%` in the weakest three modes. The current median absolute gradient was `1.92598e-8`. At the reproduced step-4096 update, the actual Adam denominator used median `sqrt(v_hat) = 1.10504e-6`, so `eps=1e-6` contributed about `47.5%` at that median; the second moment still retained earlier gradients. Epsilon reduction improved the 256-step screen but did not by itself finish recovery under the original learning rate.

The frozen diagnosis is `data/70-small-recovery-v3-diagnosis/residual-diagnosis.json`.

## Recovery witness

At update 4096, the final run saved `q`, the accepted equilibrium, the gradient, and the complete Adam `m/v/t` state before changing the learning rate. Keeping `eps=1e-6`, the target, loss multiplier, controls, and Adam moments fixed, it calibrated one new learning rate so the next physical step returned to the already declared twice-baseline value.

| quantity | value |
| --- | ---: |
| old learning rate | `0.0035403437409342554` |
| recalibrated learning rate | `0.1205714831013498` |
| learning-rate multiplier | `34.0564` |
| next projected stress-step RMS | `1.3921905346886253e-4 MPa` |
| next-step multiplier over baseline | `2.000000` |
| projection RMS at calibration | `2.69e-16` |

The recovery gate was reached at update 5371, after 1275 updates at the recalibrated rate. Terminal displacement RMS was `0.0001293475`, giving error / target motion `0.0009998673`. The projected-gradient mapping fell to `4.5334e-10`, or `1.43574e-5` of its initial value. All 5372 measured recovery states passed the unchanged forward acceptance rule. The terminal stress tensors remained inside the box, with eigenvalues from `0.00886824` to `0.0712079 MPa`.

This is a round-trip displacement witness. The recovered stress differs from the generating stress by RMS `0.00570704 MPa`, which is allowed because the inverse stress is not unique.

## Decision

Use `adam_eps=1e-6` as the small-fixture candidate for the face probe. The face probe must preserve its own gradient and Adam moments and calibrate its first physical step at the saved face checkpoint. Neither toy learning rate is transferred.

The passed machine-readable result is `data/70-small-recovery-v4/summary.json`. Supporting files include `calibration.json`, `implicit-gradient-check.json`, per-arm traces and solver receipts, endpoint NPZ/VTU files, and `recovery-traces.png`/`.pdf`. The step-4096 optimizer state and its frozen calibration receipt are under `data/70-small-recovery-v4/recovery-candidate-eps-1e-6/`.

Earlier output directories are preserved. The first run exposed an overly small finite-difference step, v2 exposed a step-zero trace indexing defect before optimization, and v3 completed the declared 4096-update phase but correctly failed the recovery gate.
