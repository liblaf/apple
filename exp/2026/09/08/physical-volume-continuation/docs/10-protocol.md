# Physical-volume continuation protocol

The approved sequence starts with the exact corrected step-200 checkpoint and extends the original optimization to step 400 in two blocks of 100 updates. Material law, phase constants, fixed vertices, uniform coordinate MSE, Raw6 controls, and Adam settings remain identical. Each resumed evaluated checkpoint consumes its saved exact gradient once and retains both Adam moments. No inverse stationarity is assumed from a finite update budget.

Every evaluation records global fit, motion, target projection, the previously fixed nasolabial and three marked-region errors, actual control and geometry increments, and the existing 5 mm rest-normal high-pass displacement and target residual. These are diagnostic measurements; no smoothing is applied to geometry. Render the fixed views and horizontal sections at each block endpoint. The target-space region boxes are frozen from the closeup report and are approximate, overlapping regions.

This is a diagnostic continuation of a state containing an inverted tetrahedron, not a physically valid baseline. Grandfather only global cell 573586. Stop before accepting a gradient or updating the accepted/best states if any other cell inverts, if any determinant is nonfinite, or if the known cell falls below its step-200 determinant minus 0.001 (J < -0.3046486160938099). If that cell recovers, latch recovery and stop on a later reinversion. Save any rejected evaluated geometry separately. Also stop visibly on unsuccessful forward/adjoint solves or nonfinite loss/gradient. Do not repair geometry, clamp controls, or change learning rate within the baseline continuation.

After each block, compare the original and endpoint measurements and actual geometry. A nasolabial RMS improvement below 1% while global RMS improves by more than 3% over a block triggers a short, separately recorded nasolabial-weighted objective branch with the same mechanics. This tests whether prioritizing that region yields additional local progress; failure does not prove mechanical impossibility. If both measures stall, inspect gradients and actual optimizer increments before attributing failure to mechanics.

Separately, compare one weak spatial activation penalty against the unregularized continuation from a common evaluated checkpoint. Use same-muscle adjacent cells and document the graph, normalization, and weight. Start with a penalty gradient about 1% of the data gradient RMS, retain the original Adam moments, and compare matched target fit and motion as well as roughness and fold sections. This is an ablation of activation freedom; it does not establish anatomical validity.

Only if those controlled tests leave the fold discrepancy unresolved should skin or attachment mechanisms be introduced, starting in a small controlled model. Preserve historical experiments, runtime libraries, and unrelated repository changes. New sources and outputs are isolated in this group; no commits or pushes are part of this experiment.
